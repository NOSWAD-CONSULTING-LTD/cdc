CDC AI Readiness Evidence Pattern

This diagram shows how a user question should move through approved query templates, graph evidence, CDE semantics, document provenance, and answer controls. It is a demo reference architecture, not a validated GxP workflow.

Question And Retrieval

User Question
Example: Which evidence documents support inline NIR blend uniformity?
↓
Approved Template
evidence_documents_for_cde binds cdeId. The agent does not invent arbitrary Cypher.
↓
RAG Manifest
docs/rag-manifest.jsonl points the agent to relevant docs: handbook, glossary, ontology, CDE catalog, and query packs.
↓
Answer Guardrails
Expected-answer checks require evidence IDs and reject unsafe claims such as real approval or validated GxP status.

Graph Evidence

CDE Definition
CriticalDataElement stores definition, owner, steward, source system, standards, CMC section, and quality rules.
↓
Observed Value
CDEValue stores a demo observed value and links to ValueDomain, UnitOfMeasure, and ManufacturingRun.
↓
Execution Evidence
SensorReading, Alarm, Deviation, BatchRecord, and QAReleaseDecision show what happened.
↓
Document Evidence
EvidenceDocument, ValidationEvidence, and ProvenanceStatement provide citation-style context.

Answer And Audit

Grounded Answer
Answer uses rows returned by Neo4j and includes IDs, document titles, statuses, summaries, and limitations.
↓
Semantic Checks
The answer preserves distinctions: CDE definition vs CDE value, process parameter vs quality attribute, release vs reject.
↓
Validation Checks
cypher/10_ai_readiness_checks.cypher and cypher/11_graph_integrity_checks.cypher check metadata, evidence, and structure.
↓
Residual Limits
Demo data is fictional and incomplete. Neo4j Community does not provide server-enforced read-only RBAC.
Key graph pattern:
CDEValue -> CriticalDataElement -> ValueDomain -> UnitOfMeasure
Evidence pattern:
EvidenceDocument -> CDEValue / StandardMapping / QAReleaseDecision
Disposition pattern:
QAReleaseDecision -> RELEASES or REJECTS -> ManufacturingRun
Agent pattern:
Question -> Template -> Rows -> Checked Answer
